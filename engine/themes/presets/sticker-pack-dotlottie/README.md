# Sticker Pack (.lottie)

A six-sticker variety pack rendered as a single browse-able `.lottie` bundle so chat and messenger surfaces can ship them as one drag-and-drop file. Each sticker is square (256x256), loops at three seconds, and stays bold enough to read at 64-pixel preview size. The preview in this directory cycles all six concepts in a single playback so designers can scan the variety at a glance — the actual export from the engine fans these out into discrete `.lottie` entries inside the pack manifest. Use the `playful` theme for high-saturation palettes; the cast suggestion only includes a generic `sticker_shape` so the AI director can riff freely on silhouettes (rounded squares, blobs, triangles, badges). The 3-second cap keeps file size friendly for messengers that throttle uploads.
